# Subnautica 2 MCP

Independent code repository for the Subnautica 2 native runtime MCP bridge in Unreal Game Runtime MCP.

Implementation has not started. New bridge development begins at `0.1.0`; this repository entry point is not an implemented release.

Detailed documentation and work tracking belong to the central repository:

- [Bridge assessment and state](../docs/bridges/subnautica-2/README.md).
- [Project rules](../AGENTS.md).
- [Development workflow](../docs/development.md).

Common Unreal functionality may be reused or extracted within assigned development. Subnautica's discovery, engine ABI, loading, lifecycle, and gameplay tools require their own confirmed integration.
